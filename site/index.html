Install in a minute

Pick your browser.

  1. Download the latest package and unzip it into a folder you'll keep.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and select the unzipped folder.
  5. Open Twitch. That's it.
Download for Chrome / Edge / Brave
  1. Click Install for Firefox below.
  2. Click Continue to Installation, then Add.
  3. Open Twitch. NoBreak is signed by Mozilla and updates itself.
Install for Firefox

Requires Firefox 140 or newer.

FAQ

Is it free?

Yes. NoBreak is free and open source. There's no paid tier and no account.

Why isn't it on the Chrome Web Store?

NoBreak is distributed through GitHub releases, so Chrome-based browsers install it with Developer mode. Firefox gets a Mozilla-signed version that installs normally.

Does it collect any data?

No. Stats are stored only in your browser. The extension talks to Twitch and checks GitHub for new versions, nothing else.

I still see ads or a purple screen. What now?

Make sure you're on the latest version, disable other Twitch ad blockers and reload the tab. If it persists, report it on GitHub.

Who makes the ad-blocking engine?

The vaft engine is by pixeltris/TwitchAdSolutions (MIT). NoBreak packages it and adds the watchdog, conflict detection, stats and automatic updates.
